## Brand & Style

This design system delivers an executive-grade, high-confidence aesthetic tailored for enterprise compliance, operational analytics, and proof-validation platforms. It blends high-clarity **Modern Corporate** structure with surgical, contemporary software polish.

### Brand Personality
- **Authoritative & Defensible:** Inspires unshakeable trust during audits, reviews, and data reconciliation.
- **Architectural & Crisp:** Content is organized into clean visual planes; every metric, badge, and proof point sits with deliberate intention.
- **High-Velocity Utility:** Designed for dense, complex workflows without inducing cognitive fatigue.

### Emotional Response
Users should feel in total control: calm under high-stakes data reviews, confident in automated verification mechanisms, and supported by clear typographic and semantic hierarchy.

### Visual Aesthetic
The style pairs a crisp off-white canvas with sharp, elevated white analytical cards, framed by an authoritative, commanding deep navy sidebar. Focused electric blue accents direct focus to interactive primary tasks, while an expressive spectrum of semantic tones marks verified truths, warnings, and contradictions.

## Colors

The palette establishes an immediate hierarchy between spatial navigation, analytical content surfaces, and actionable data states.

### Core Canvas & Surfaces
- **App Canvas Background:** `#F8FAFC` (Slate 50) creates a calm, glare-free working plane.
- **Sub-Surface / Header Layer:** `#F1F5F9` (Slate 100) for structural table headers, inset wells, and metadata bars.
- **Primary Card Surface:** `#FFFFFF` (Pure White) with hairline borders for elevated data containers.
- **Persistent Left Navigation:** Deep Executive Navy (`#0F2042`) providing grounded structural anchor.

### Core Brand Tokens
- **Primary Electric Blue:** `#2563EB` (Hover: `#1D4ED8`, Sub-accent: `#3B82F6`, Tint: `#EFF6FF`). Used for primary CTAs, active selection tabs, and critical focus rings.
- **Structural Navy:** `#0F2042` (Surface Variant: `#152A56`, Nav Border: `#1E3A70`).
- **Intelligence & AI Accent:** `#8B5CF6` (Darker: `#7C3AED`, Light Fill: `#F5F3FF`). Dedicated to machine-generated insights, automatic proofs, and automated summarizations.

### Text & Contrast Hierarchy
- **Heading & Value Text:** `#0F172A` (Slate 900) for maximum typographic contrast.
- **Body & Primary Readout:** `#334155` (Slate 700) to `#475569` (Slate 600) for long-form narrative.
- **Muted & Metadata Text:** `#64748B` (Slate 500).
- **De-emphasized & Form Labels:** `#94A3B8` (Slate 400).
- **Navigation Active Text:** `#FFFFFF`.
- **Navigation Inactive Text:** `#94A3B8` (Hover: `#F8FAFC`).

### Semantic Color Matrix
- **Success / Verified:** `#10B981` (Dark: `#059669`, Tint: `#ECFDF5`). Indicates authenticated records, verified assertions, and pass states.
- **Warning / Review Required:** `#F59E0B` (Dark: `#D97706`, Tint: `#FFFBEB`). Flags threshold drift and pending approvals.
- **Danger / Contradiction:** `#EF4444` (Dark: `#DC2626`, Tint: `#FEF2F2`). Highlights audit failures, data conflicts, and unproven claims.
- **Info / Traceability:** `#0EA5E9` (Dark: `#0284C7`, Tint: `#F0F9FF`). Denotes informational tooltips, systemic logs, and audit trails.

## Typography

Typography relies on **Inter** configured with tight tracking for headlines and calibrated baseline heights for high numerical data density.

### Typographic Principles
- **Crisp Weight Contrast:** Jump decisively between weights (`700` and `600` for titles, `400` for general content, and `500` for inputs and action anchors).
- **Uppercase Data Labels:** Field tags, table header keys, status groups, and metric labels use `label-caps` (`11px`, `font-semibold`, uppercase, `letter-spacing: +0.06em`) in slate-400 or slate-500.
- **Tabular Numerics:** All numbers, financial indicators, and proof hashes must enforce tabular numerals (`font-feature-settings: 'tnum' on, 'zero' on`) to ensure alignment across data rows.
- **Code Tokens:** Proof IDs, transaction receipts, and SHA-256 validation digests employ `JetBrains Mono` at `code-sm` to convey computational authority.

## Layout & Spacing

The structural layout uses an **App Shell + Fluid Grid** model.

### Spatial Architecture
- **Sidebar Shell:** A rigid, non-collapsing 260px wide bar (or 72px iconified rail) pinned to the left edge with a fixed vertical height (`100vh`).
- **Main Viewport Canvas:** Spans the remaining horizontal space with a responsive fluid container capped at an optimal reading width of `1680px`.
- **Grid Layout:** An internal 12-column fluid grid system utilizing a strict 8px structural base rhythm.
  - Desktop (`>= 1280px`): `margin: 2rem`, `gutter: 1.5rem`.
  - Tablet (`768px - 1279px`): `margin: 1.5rem`, `gutter: 1rem`. 12 columns collapse into 8 or 4 column groupings.
  - Mobile (`< 768px`): Sidebar transforms into an off-canvas drawer. `margin: 1rem`, `gutter: 1rem`. Dashboard card stacks collapse to 1 column.

### Rhythm Guidance
- Apply `space-xs` (4px) and `space-sm` (8px) for internal pill padding, inline icons, and input field internal spacing.
- Apply `space-md` (16px) for card body padding and horizontal form field splits.
- Apply `space-lg` (24px) for analytical metric card padding and modular panel separators.
- Apply `space-xl` (32px) for page section stacking and KPI board groupings.

## Elevation & Depth

Visual depth is achieved through **ambient diffused shadows** combined with **subtle hairline borders**, keeping surfaces light and floating rather than heavy or muddy.

### Elevation Hierarchy
1. **Canvas Base (Level 0):** `#F8FAFC`. Zero elevation.
2. **Standard Elevated Card (Level 1):** `#FFFFFF` surface with a crisp structural hairline `border: 1px solid #E2E8F0` (or `rgba(0, 0, 0, 0.05)`) and shadow:
   `box-shadow: 0 1px 3px 0 rgba(15, 23, 42, 0.03), 0 1px 2px -1px rgba(15, 23, 42, 0.03);`
3. **Hover Lift Card (Interactive Level 2):** Applied when cards act as drill-downs or selectors:
   `transform: translateY(-2px);`
   `box-shadow: 0 10px 15px -3px rgba(15, 23, 42, 0.06), 0 4px 6px -4px rgba(15, 23, 42, 0.03);`
   `border-color: #CBD5E1;`
4. **Dropdowns & Popovers (Level 3):**
   `box-shadow: 0 20px 25px -5px rgba(15, 23, 42, 0.08), 0 8px 10px -6px rgba(15, 23, 42, 0.03);`
5. **Modals & Confirmation Drawers (Level 4):** Backed by an overlay tint (`rgba(15, 32, 66, 0.45)` with `backdrop-filter: blur(4px)`) and a high-order shadow:
   `box-shadow: 0 25px 50px -12px rgba(15, 23, 42, 0.18);`

### Icon Glow & Micro-Luminescence
When semantic icons are placed inside utility containers, pair a 10% opacity semantic background tint with an ultra-soft radial halo matching the stroke color (e.g., `#2563EB` with `box-shadow: 0 0 12px rgba(37, 99, 235, 0.2)`).

## Shapes

The geometric architecture balances precision engineering with modern softness. 

### Geometric Scale
- **Large Analytical Cards & Outer Panels:** `rounded-xl` to `rounded-2xl` (`12px` to `16px`). Prevents dashboard tiles from feeling clinical while maintaining crisp boundaries.
- **Buttons, Text Inputs, & Select Menus:** `rounded-lg` (`8px`). Strikes the ideal balance between functional clickability and form factor stability.
- **Badges, Status Chips, & Filter Pills:** `rounded-full` (`9999px`) or `rounded-md` (`6px`) depending on context:
  - Metric status badges and category chips use `rounded-full`.
  - In-table verification tags and data-density chips use `rounded-md` (`6px`) to conserve vertical and horizontal rhythm.
- **User Avatars & Verification Check-Pills:** Strictly `rounded-full`.

## Components

### Buttons
- **Primary Action:** Solid `#2563EB` fill, white text, `font-medium`, `rounded-lg` (8px), padding `10px 18px`. Hover: `#1D4ED8` with `box-shadow: 0 4px 12px rgba(37, 99, 235, 0.25)`. Active: `#1E40AF`.
- **Secondary / Neutral:** Pure white fill, `#E2E8F0` border, `#334155` text. Hover: `#F8FAFC` background, `#CBD5E1` border.
- **Ghost / Tertiary:** Transparent background, `#64748B` text. Hover: `#F1F5F9` background, `#0F172A` text.
- **Danger:** Solid `#EF4444` or transparent with `#EF4444` text and red hover wash (`#FEF2F2`).

### Navigation Sidebar Items
- **Inactive Item:** Padded pill (`8px 12px`), `rounded-lg`, `#94A3B8` icon and text. Hover: `#152A56` background, `#FFFFFF` text.
- **Active Item:** Solid electric blue background (`#2563EB`), crisp `#FFFFFF` text, font weight `600`. Features a faint forward glow: `box-shadow: 0 2px 8px rgba(37, 99, 235, 0.4)`.

### Status Badges & Proof Chips
- Composed of an 8px circular indicator dot, an uppercase `label-caps` title, and a soft tinted background.
  - **Success (Verified):** Background `#ECFDF5`, text `#065F46`, border `#A7F3D0`.
  - **Warning (Review):** Background `#FFFBEB`, text `#92400E`, border `#FDE68A`.
  - **Danger (Contradiction):** Background `#FEF2F2`, text `#991B1B`, border `#FECACA`.
  - **Intelligence (AI Summary):** Background `#F5F3FF`, text `#5B21B6`, border `#DDD6FE`.

### Input Fields & Controls
- **Inputs & Selects:** Height `40px`, background `#FFFFFF`, border `1px solid #CBD5E1`, `rounded-lg`. Typography is `body-md` in `#0F172A`. Placeholder in `#94A3B8`.
  - Focus state: `border-color: #2563EB`, `box-shadow: 0 0 0 3px rgba(37, 99, 235, 0.15)`.
- **Checkboxes & Radios:** Native size 16px. Inactive: `#FFFFFF` with `#CBD5E1` border. Checked: `#2563EB` fill with white checkmark.

### Cards & Analytical Containers
- Built on `#FFFFFF` with `rounded-xl` (12px), bordered by `rgba(0, 0, 0, 0.06)`, and Level 1 elevation.
- Standard layout contains:
  - Header: Sub-title (`label-caps` in `#64748B`) followed by an icon with matching semantic tint.
  - Core Metric: Large tabular display (`headline-xl` in `#0F172A`).
  - Footer Trend: Inline badge accompanied by contextual description (`body-sm` in `#64748B`).

### Interactive Feedback & Tooltips
- **Tooltips:** Inverted appearance using `#0F172A` background, `#F8FAFC` text, `rounded-md` (6px), padding `6px 10px`, `caption` typography with high-contrast micro-shadow.
- **Hover Lift:** Cards with pointer interactions transition using `transition: all 180ms cubic-bezier(0.16, 1, 0.3, 1)`.
